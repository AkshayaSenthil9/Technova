## How to run
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge, or another modern browser.
3. Choose a support category or type a query, then click **Get help**.
4. For order tracking, use demo ID `QC123` (shipped) or `QC456` (delayed).

This is a simulated front-end demo. It does not connect to a real store, carrier, or customer database. The email address is a placeholder and should be replaced with the institution's approved contact before any public deployment.

## Project contents
- `index.html` – support interface
- `style.css` – responsive styling
- `script.js` – query matching and automated replies
- `Project_Report.md` – complete activity report, workflow, test results, reflection, and AI-use notes
- `screenshots/` – place screenshots of your running project here before submission

## Safety and privacy
Only fictional demo order IDs are used. The interface warns users not to provide passwords, OTPs, PINs, or payment details.
